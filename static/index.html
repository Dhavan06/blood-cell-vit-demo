Blood Cell Vision Transformer

A ViT that classifies blood cells (RBC / WBC / Platelets) from microscopy images and benchmarks its differential counts against ground truth using Bland-Altman agreement — a portfolio project built to explore automated haematology analysis.

GitHub repo  ·  Full notebook write-up

🩸 Try a single cell image

Upload one cropped cell image and the model will classify it.

🧪 Bring your own dataset

Upload a batch of cell images — any dataset, not just the demo one. Optionally add a labels.csv (columns: filename,label and optionally group) with reference labels to get live accuracy and Bland-Altman benchmarking against your own ground truth, the same methodology used to validate the model in the notebook.



⚡ No dataset handy? Run the built-in demo

Runs the model live on a bundled sample of BCCD microscopy fields with known ground truth, and shows the full classification + differential-count benchmarking pipeline.

Honest scope: trained on the public BCCD dataset (RBC / WBC / Platelets, not a full 5-part WBC differential) with a Vision Transformer trained from random initialisation (no internet access to a pretrained checkpoint in the build environment). Architecture and benchmarking methodology are written to scale directly to a full differential dataset and a pretrained ViT checkpoint. See the README for details.
